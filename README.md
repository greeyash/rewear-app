# ReWear — Sustainable Fashion Marketplace

> "Where Old Fashion Meets New Impact"
> Top 8 Finalist — Technoday Hackathon 2025

## About
ReWear is a web-based circular economy platform that enables users to
buy, sell, and donate second-hand clothing. Built to address Indonesia's
2.3 million tons/year textile waste problem, ReWear combines AI-powered
quality grading with verified donation management to promote sustainable
fashion consumption.

## Core Features
- **AI-Assisted Grading** — Automatically classifies clothing condition
  (Grade A–D) based on uploaded flat-lay photos
- **Verified Donation System** — Campaign-based donations with real-time
  progress bar and post-distribution accountability reports
- **Impact Feedback** — Per-transaction CO₂ and textile waste savings
  estimation displayed to users
- **Secure Marketplace** — Identity verification, user rating system,
  and transaction protection

## Tech Stack
- **Frontend:** Next.js
- **Backend & Database:** Supabase (PostgreSQL)
- **Auth:** Supabase Auth
- **AI Grading:** Gemini API
